# One-Stop Personalized Career & Education Advisor

## 📌 Project Overview
This project aims to develop a personalized career and education guidance platform for students. The system will help students explore graduation courses, government colleges, career opportunities, and suitable career paths based on their academic background, interests, and skills.

## 🎯 Objectives
- Provide personalized career guidance
- Help students understand different graduation courses
- Recommend suitable courses based on student information
- Help students find suitable government colleges
- Provide information about career opportunities
- Generate a personalized career roadmap
- Provide AI-based education and career guidance

## 🛠 Technology Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Java + Spring Boot
- Security: Spring Security + JWT
- Database: MySQL
- AI Module: Gemini + RAG
- ML Module: Python + Machine Learning
